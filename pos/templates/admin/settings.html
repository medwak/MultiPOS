How M-Pesa works here

The cashier enters the customer's number and the customer gets a PIN prompt (STK push). The till confirms automatically.

Confirmation: if a public HTTPS callback URL is set, Safaricom tells us instantly and we store the M-Pesa receipt code. Without it, the server asks Safaricom for the result after ~12 s (works on a local network, but the receipt code is not returned).

Getting keys: create an app on developer.safaricom.co.ke (sandbox shortcode is 174379 and the sandbox passkey is shown on the portal's test credentials page). For live payments apply for Go-Live with your Paybill/Till.

Paid without a prompt? Cashiers can also type the code from the customer's M-Pesa SMS under "M-Pesa code".
